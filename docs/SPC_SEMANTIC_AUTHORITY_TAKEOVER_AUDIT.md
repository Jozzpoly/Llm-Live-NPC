# 1. Stop condition

**Do not promote current `ResidentCognitionProposal.activityDirective` + `ResidentCognitionOwner` + `CognitionGrounder` as the final live-provider path.**

The current legacy cognition path still expresses semantic cognition as:

`event reasons`
→ `LLM proposal`
→ `KEEP / STOP / REPLACE current activity`
→ `ground directly to ResidentActivity`

That path predates the recovered resident matter/run authority.

If connected to a live model as-is, the LLM would still directly choose/replace bodily activity while K0–K5 matter/run authority exists beside it as a partially bypassed subsystem.

That would recreate dual authority at the semantic/execution boundary.

# 2. Current competing authorities

## 2.1 Recovered matter authority

`ResidentContinuityKernel` now owns:

- persistent matter identity;
- active/suspended/terminal lifecycle;
- semantic course;
- matter-scoped semantic revision;
- live semantic evidence dependency;
- scoped provider proposal authority;
- exact task/run binding;
- factual outcome reconciliation;
- immediate run mutation revocation when semantic authority disappears.

This is the currently defended continuity direction.

## 2.2 Legacy LLM concerns

`ResidentMind` separately owns `concerns`:

- open/resolved status;
- priority;
- evidence IDs;
- LLM may create/update/resolve them;
- open concerns are sorted toward the front of cognition context.

This is potentially a **second goal/motivation system** unless its role is narrowed.

A live matter and an LLM concern must not independently claim to represent the same resident commitment.

## 2.3 Legacy direct bodily activity authority

`ResidentCognitionProposal.activityDirective` allows the model to:

- keep current activity;
- stop current activity;
- replace current activity with idle/travel/follow/communicate/investigate.

`CognitionGrounder` converts that directly into a `ResidentActivity`.

The resulting activity has no matter ID, semantic revision or exact run provenance.

This is incompatible with the recovered authority model as a final path.

## 2.4 Legacy resident-global stale authority

`ResidentCognitionOwner` still protects attempts using resident-wide:

- `attentionRevision`;
- `activityRevision`.

K0–K4 instead re-earned matter-scoped semantic authority.

The two stale-authority systems answer different questions and must not both remain architecture owners.

## 2.5 Legacy event-reason scheduler

`CognitionScheduler` currently queues unique `CognitionReason` records by ID.

Useful mechanisms worth preserving include:

- minimum cadence;
- urgent cadence;
- debounce;
- stable per-resident staggering;
- adaptive quiet review scheduling.

But its current **unit of pending work** is an event/reason, not an unresolved semantic discrepancy or matter.

This risks historical backlog and duplicate reconsideration in a dense living world.

## 2.6 K5 composable effects are not yet composable authority

`ResidentWorldExecutionFrame` can contain motion + speech, which is a major improvement over legacy `move OR speak`.

However one frame still carries exactly one `runId`.

Therefore all effects in that frame are currently owned by one run/matter revision.

The first life slice must test whether this is sufficient or whether independent execution resources/channels need separate ownership.

Do not design a general body-resource scheduler before that pressure exists.

# 3. Refined conceptual layers

Current research supports the following distinctions.

## Matter

Something that remains unresolved/important in the resident's life.

Examples:

- deliver the workshop crate;
- deal with a request from another resident;
- find out why an expected object is missing.

A matter may remain live while not currently owning bodily execution.

## Semantic course

The resident's currently committed interpretation/direction for a matter.

Example:

- `carry crate to market storage`;
- later revise to `search last-known workshop location`;
- later revise to `ask Mira whether she moved it`.

This is closer to an **intention/commitment** than a raw desire or body command.

## Focus / execution ownership

Which matter/run currently owns scarce execution resources.

Potential resources include:

- locomotion;
- attention/facing;
- communication;
- manipulation/hands/action;
- possibly other future channels.

No final resource model is decided yet.

## Task/run

A concrete local attempt/skill execution grounded from one semantic revision.

Examples:

- approach crate;
- pick it up;
- carry toward destination;
- search last-known position;
- approach speaker.

## Factual outcome

What World actually resolved.

Mechanical success/failure is evidence for the matter, not automatic semantic resolution.

# 4. External sanity check: commitment vs continual replanning

Classical BDI work distinguishes intentions from desires/goals because intentions represent commitments that resist constant reconsideration. Reconsideration policy determines when a changing environment justifies reopening that commitment.

Embodied cognitive-architecture work also supports selecting multiple non-conflicting behaviors in parallel rather than assuming one global action at a time.

These are direction checks, not architecture authority.

Useful references:

- Schut & Wooldridge, *Principles of intention reconsideration*;
- Frontiers, *Dynamical Intention: Integrated Intelligence Modeling for Goal-Directed Embodied Agents*;
- LIDA embodied intelligence / smooth coping work on parallel non-conflicting action selection.

SPC implication:

> do not turn every percept into replanning; do not turn every live matter into the one current body action.

# 5. Required properties of the successor live-provider path

No exact JSON schema is frozen yet, but the successor must satisfy these properties.

## 5.1 Model output is matter-scoped

A real semantic request must bind to an exact:

- resident;
- matter;
- matter semantic revision;
- live semantic evidence dependency;
- provider attempt identity.

K4 already provides the local authority membrane for this.

## 5.2 Model does not directly own body activity

Provider output may revise semantic meaning/course, but local grounding/execution must translate that into tasks/runs under exact matter authority.

The provider must not directly emit the final equivalent of:

`ResidentActivity = travel/follow/communicate/...`

without an intervening matter-owned grounding/execution layer.

## 5.3 Existing commitment can remain unchanged

A semantic review must be able to conclude that the current course still stands.

Not every review creates a new plan or new matter.

## 5.4 Matter lifecycle changes are explicit

The future provider path may eventually need bounded semantic dispositions such as:

- preserve current course;
- revise current course;
- conclude/resolve matter;
- abandon/cancel matter;
- possibly adopt/refuse a candidate new matter.

This list is **not yet the final schema**. The first material life slice should determine the minimum honest set.

## 5.5 Belief updates remain evidence-grounded

Beliefs may still be useful, but they must not become hidden goal authority.

T2 must first prevent live semantic beliefs from citing evidence that can no longer be reconstructed.

## 5.6 `concerns` require a role decision

Before live-provider integration, current LLM-managed concerns must be classified as one of:

- non-authoritative attention/discrepancy notes;
- candidate matters awaiting explicit adoption;
- deprecated legacy representation to be removed/migrated.

They must **not** remain a second independent persistent goal stack beside matters.

## 5.7 Scheduling should converge toward semantic pressure

Event arrivals should update evidence and potentially matter/discrepancy state.

The scheduler should increasingly answer:

> which unresolved semantic pressure genuinely requires review now?

rather than:

> which historical event reasons are still in the inbox?

Cadence/debounce/stagger mechanisms can survive this change.

# 6. First material slice should falsify execution-resource assumptions

The proposed Janek crate slice is useful partly because it can expose whether one foreground run is enough.

Example interruption while carrying:

- delivery matter remains meaningful;
- physical possession of the crate may remain World truth without continuous semantic command;
- player communication may require attention/facing/speech;
- locomotion may pause, continue or change depending on situation;
- manipulation state may remain stable;
- a social request may or may not become a new continuing matter.

Possible outcomes:

### Outcome A — one foreground run is sufficient

A single matter-owned execution can locally compose required channels without semantic confusion.

Then avoid inventing channel-level authority prematurely.

### Outcome B — independent channel ownership is required

For example, one matter needs locomotion while another temporary social interaction legitimately owns attention/speech.

Then introduce the smallest explicit execution-resource ownership model justified by evidence.

Do not assume Outcome B in advance.

---

# 7. Matter interruption needs semantic vs execution distinction

Current matter `suspended` state is useful and defended, but the first life slice should test whether every ordinary interruption should semantically suspend the matter.

Potentially distinct situations:

- **semantic suspension** — the resident genuinely defers the matter because another matter supersedes it;
- **execution hold** — current run/body channels pause temporarily while the matter remains active and semantically unchanged;
- **parallel non-conflicting behavior** — some body channels serve another interaction while the original matter remains active and possibly keeps another channel.

Do not collapse all three into `matter.status = suspended` merely because the prototype can.

# 8. Candidate semantic-pressure ladder

Research hypothesis only:

1. **routine continuation** — local brain;
2. **mechanical correction** — local brain;
3. **local alternate/cooperation choice** — local brain, potentially Companion donor;
4. **known affordance/search problem** — local skills/search;
5. **semantic discrepancy** — LLM reconsideration.

Examples of Level 5:

- expected target remains absent after grounded local search;
- new evidence contradicts the matter's semantic assumption;
- two genuine continuing matters conflict;
- socially meaningful request requires adoption/refusal/reprioritization;
- danger or novel condition changes what the matter means;
- local skills cannot decide without semantic judgement.

This ladder is intended to protect the local brain from becoming an LLM executor and protect the LLM from becoming an event processor.

# 10. Promotion boundary

A live-provider path is not qualified merely because:

- the worker returns valid JSON;
- the model produces plausible activity text;
- `ResidentActivity` changes correctly;
- provider retries/stale responses are handled.

The stronger gate is:

> **the model may revise one resident-owned matter under scoped causal evidence, the local brain grounds that revision into exact authorized execution, and no parallel concern/activity/provider mechanism can bypass or contradict that matter authority.**

Until that is demonstrated, live model integration remains an experiment, not the recovered SPC cognition architecture.
