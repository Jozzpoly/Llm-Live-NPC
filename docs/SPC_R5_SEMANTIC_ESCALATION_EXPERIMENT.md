## 1. Why R5 exists

The September stress failure showed that semantic cognition can become a substitute for life.

R1–R4 recovered the opposite foundation:

- local causal life can proceed without provider novelty;
- perception does not automatically become semantic pressure;
- resident-owned history can create significance;
- affordance availability does not automatically become obligation;
- a direct non-player contact can legitimately cross the relevance boundary;
- local physical/social acknowledgement can remain separate from semantic interpretation.

R4-D deliberately stops at one clean unresolved state:

- Mira's body is idle;
- bounded local contact is complete;
- one exact addressed-speech `CognitionReason` remains unresolved;
- no fake matter exists merely to make that reason fit an API;
- no provider has been called.

R5 asks whether higher cognition can enter **there**, do bounded semantic work, and leave again.

## 2. Core R5 hypothesis

> **Provider cognition can be a sparse semantic escalation layer over an already-living resident rather than the mechanism that keeps the resident alive.**

A valid provider burst begins with existing resident-owned semantic pressure.

It may:
- accept a bounded continuing commitment;
- decline it;
- defer it;
- request clarification;
- update grounded beliefs/concerns.

It may not:
- create World truth;
- grant itself body authority;
- execute movement or speech directly;
- invent an unobserved actor/place/object/outcome;
- create a semantic reason merely because time passed;
- recursively request itself because the previous request completed.

## 4. Architectural correction exposed by R4-D

Do **not** route the R4-D `heard_speech` reason through the older matter-scoped semantic host merely because it already exists.

That would invert causality:

`reason -> fabricate matter -> provider`

instead of:

`reason -> semantic judgement -> optional admitted matter`.

The R5 path must remain reason-native until semantic judgement actually warrants a continuing commitment.

## 5. R5-A — one semantic discrepancy, one causal commitment

R5-A is deliberately small.

### 5.1 Scene

Use a compact no-player Mira/Ida specimen.

Requirements:

- Mira and Ida are real resident actors;
- Mira is already owned by recovered causal-life substrate;
- no pre-existing Mira matter is needed;
- World can remain quiet before the event;
- Ida is legally perceived/recognized by Mira;
- provider work is initially deterministic/injected, not real OpenAI usage.

R5-A does not need to repeat every R4-D material-density proof.
R4-D remains the authority for negative capability.

### 5.2 Trigger

Ida produces one physically valid addressed utterance whose semantic content cannot be honestly settled by generic local-contact acknowledgement alone.

The utterance must support a currently executable bounded semantic consequence.

First preferred specimen:

> Ida addresses Mira with a small direct social question/request for which a meaningful reply to Ida is a valid bounded `communicate` commitment.

Do not use:
- player instruction;
- hidden World information;
- future-object workflow unsupported by current causal execution;
- arbitrary chore injection.

### 5.3 Exact pressure

Before cognition:

- Mira owns exactly one unresolved `heard_speech` reason for the semantic stimulus;
- the reason cites exact private percept evidence;
- actor identity is resident-known through legal perception;
- no durable commitment matter exists yet;
- body may remain idle.

### 5.4 One provider attempt

After scheduler eligibility:

- exactly one cognition batch is taken for the causal reason;
- exact resident-private context is frozen;
- exact resident-life view is frozen;
- one provider request begins;
- repeated World ticks while it is in flight do not begin another request for the same causal version.

The provider request is **not** proof that a commitment exists.

### 5.5 Latency and inert completion

While provider work is unresolved:

- World continues advancing;
- resident body remains legal;
- local perception can continue;
- no commitment matter/run appears merely because transport exists.

When transport completes:

- the arrival sits inert;
- no World mutation;
- no matter creation;
- no body focus;
- no semantic-pressure settlement.

Only a later explicit resident/World-owned admission boundary may consume it.

### 5.6 First accepted path

The deterministic R5-A provider proposal should:

- name the exact speech reason as `originReasonId`;
- choose `accept`;
- propose one `communicate` intent targeting known Ida;
- use a small natural reply;
- cite no invented evidence.

Admission must independently re-ground:

- exact speech occurrence/percept;
- known target actor;
- current resident life fingerprint;
- current attention/activity revision;
- proposed intent shape.

Only after successful local admission may the system materialize:

- one durable resident matter;
- one exact task/run;
- body arbitration.

### 5.7 Factual consequence

The accepted communicate matter must then execute through existing resident World authority.

Required:

- Mira physically has legal contact/knowledge sufficient for the existing message executor;
- exactly one factual Mira speech occurrence carries the semantic reply to Ida;
- provider output itself never emits the occurrence;
- the matter resolves from factual execution outcome;
- run authority retires;
- body returns to idle if no other demand exists.

### 5.8 Semantic settlement / homeostasis

Admission of the accepted commitment must reconcile the exact originating cognition batch.

After successful acceptance:

- the selected `heard_speech` reason is settled;
- no older copy can resurrect it;
- no sibling reason is accidentally settled;
- provider completion does not create a replacement reason;
- ordinary completion of the causal matter does not create a semantic heartbeat.

After a long quiet continuation:

- pending semantic pressure is empty;
- no new provider request has occurred;
- no new matter has appeared;
- no repeated reply has occurred;
- no timer/quiet review has manufactured novelty.

This is the critical anti-`c181` gate.

## 11. Anti-cheat / anti-regression rules

R5 FAILS if it becomes green by:

- creating a synthetic matter before semantic judgement;
- calling provider from elapsed time alone;
- using player action as the only trigger;
- accepting provider-created hidden facts;
- letting provider output directly move/speak/mutate World;
- applying network completion from a Promise callback;
- skipping fresh local grounding;
- settling every batch reason because one reason was chosen;
- generating another cognition request from the completion of the previous request;
- adding Mira-specific branches to shared core;
- replacing one broad provider loop with a new broad provider loop;
- declaring PASS from unit tests while browser evidence is absent.

Do not commit to that abstraction until implementation pressure confirms it.
