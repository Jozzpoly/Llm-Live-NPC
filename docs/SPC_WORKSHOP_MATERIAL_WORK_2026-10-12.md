# SPC World — Workshop Bench real material use (2026-10-12)

**Scope:** one genuinely executable physical/work action in the existing five-person World, not an art-style promotion or an NPC autonomy milestone. Owner's prior rejection of generated terrain remains authoritative. No new procedural ground is introduced.

**Playable action:** bring the **Workshop Spare Parts** (real `crate.workshop.02`, not Janek's `crate.workshop.01`) to the authored **Workshop Bench** and press **U**. The action takes **180 fixed World ticks (3 seconds)**, requiring a locally held exact source, proximity and unobstructed sight to the work anchor, and a stationary actor. The World, not the key binding or animation, owns legality, progress and one-shot completion. Moving/leaving/losing the source interrupts safely. On genuine completion, World atomically retires source identity and creates the free `kit.workshop.01` repair kit next to the anchor. A World work-outcome record preserves source identity and exact output. An actual local interaction event can be witnessed by SPC with legitimate sight; it is not automatically global resident knowledge.

**Critical limitations:** One deliberately authored recipe, no general crafting or production chain, no persistent save, no labor automation, no stamina, no fictional building collider. The work anchor stays non-solid because the current World has only world-boundary actor collision. **Recovered SPC are not authorized through the player action path.** A later resident action must go through the established semantic-intent and exact-run authority. No autonomous NPC work is claimed here, nor does rendering make actual map art acceptable.

**Evidence:** Tests in `five-resident-workshop-material-work.integration.test.ts`: physical pickup, no production before tick 180, exact input consumption/output, historical identity provenance, material survival on movement interruption, forbidden resident bypass, unknown site and remote denial.
