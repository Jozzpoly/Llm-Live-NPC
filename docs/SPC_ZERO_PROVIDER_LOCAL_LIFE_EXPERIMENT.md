# SPC R1 — Zero-Provider Local-Life Experiment

Status: **LOCAL-LIFE PASS — CONTRACT SATISFIED**
Date: **2026-09-20**
Qualified source SHA: `69c40225fffaf0f97bdba95aaa36cfb1c9c3ba25`
Evidence report: `docs/SPC_ZERO_PROVIDER_LOCAL_LIFE_R1_PASS.md`
Parent authority: `docs/SPC_POST_STRESS_RECOVERY_PROGRAM.md`

This experiment is intentionally narrow.

It does **not** attempt to prove final NPC intelligence, final architecture, five-resident scalability or final game quality.

It exists to answer one foundational question:

> **Can one resident remain meaningfully alive in a causal authored world without an LLM request being required to manufacture continuity?**

Provider cognition is disabled for R1.

---

## 1. Why R1 exists

The 18 September stress observation showed that the previous integrated system could generate large amounts of technically valid cognition traffic while resident-life value remained weak.

The wrong repair would be to add only:
- cooldowns;
- longer review timers;
- TTL;
- request caps;
- token caps.

Those controls are useful safety mechanisms but can only turn a runaway dead system into a quieter dead system.

R1 therefore removes the provider entirely and asks whether the resident-local organism is worth reconnecting to higher cognition later.

---

## 2. Experimental subject

Use **one shared resident architecture**.

Mira is the preferred first subject because ordinary life exposes fake aliveness strongly:
- no task spectacle is available to carry the illusion;
- silence must be legitimate;
- small local choices matter;
- the resident must not wait for a player;
- routine must not collapse into random wandering.

Janek remains the immediate second falsifier after R1 because material work/interruption creates a different pressure.

Resident identity may provide authored initial facts/history/capabilities.
Core behavior must not branch on resident ID.

---

## 3. Environment

Do **not** use the entire sparse 8192×8192 world as the main test surface.

Create or select a deliberately bounded micro-world / neighborhood containing enough causal affordances to sustain ordinary local life.

Minimum categories:
- a home/base or personally meaningful local anchor;
- at least one purposeful material location;
- at least one manipulable or stateful object;
- at least one locally meaningful environmental/world state that can change;
- at least one traversal choice or obstruction;
- one interrupting occurrence source;
- enough spatial separation that attention/movement decisions are nontrivial.

The exact content is not important.
What matters is that resident behavior can be explained by real world facts rather than authored scenario commands.

Do not increase map size merely to make the experiment appear substantial.

---

## 4. Provider boundary

For the experiment:
- no live provider request;
- no fake LLM response;
- no deterministic "LLM stub" selecting high-level life decisions;
- no timer that periodically invents a new semantic purpose.

The resident may begin with authored private state and one or more legitimate matters.

The experiment may use deterministic scripted **World occurrences** as perturbations, because the World is allowed to change.
Those perturbations must not directly command resident behavior.

### Critical semantic boundary

R1 does **not** solve cognition-pressure relevance/lifecycle. That belongs to R2.

In particular:

`local contact acknowledgement != semantic handling of addressed speech`.

A resident may locally stop, orient and acknowledge an addressed speaker while the speech-content reason remains unresolved for later higher cognition. R1 should prove that the body/local life can continue coherently **despite** such retained pressure when provider cognition is disabled.

Therefore R1 must not earn a PASS by deleting every pending reason. The useful invariant is narrower:

- ordinary local life does not require dispatching provider requests;
- background/body handling does not automatically claim semantic settlement;
- unresolved pressure remains bounded/stable when no new causal evidence arrives;
- a new real percept may add new pressure;
- old pressure must not manufacture new World activity by itself.

---

## 5. Required resident layers

R1 should expose the smallest useful separation between:

### Private resident state
Facts such as:
- known places/objects/actors;
- current matters;
- personal relevance facts;
- local routine/history;
- remembered outcomes.

### Attention/relevance
A local mechanism able to decide that:
- some observations matter now;
- some are background;
- some relate to an active matter;
- some are already expected/resolved;
- some may interrupt current execution.

This does not need to be the final R2 semantic-metabolism architecture.
It must be stronger than "every event triggers a new task".

### Continuing matter
A purpose or concern that survives temporary bodily redirection.

### Current execution
What the body is doing now.

### Local competence
Enough procedural behavior to:
- move;
- orient/attend where relevant;
- interact with the selected small material affordance;
- recover from one local failure/obstruction;
- resume or deliberately conclude execution.

### Factual World outcome
The resident cannot self-report success.
The World owns the resulting material fact.

---

## 6. The canonical R1 life arc

Do not implement this as a hard-coded cinematic sequence.
It is an observation contract.

A successful run should naturally contain something equivalent to:

1. resident exists with private context and at least one continuing local matter;
2. resident begins or continues a grounded local activity;
3. the activity changes some factual World state or progresses toward doing so;
4. an unrelated but locally perceivable occurrence happens;
5. resident notices it;
6. local relevance decides whether it deserves attention;
7. if material enough, resident temporarily redirects attention/body;
8. original matter remains present rather than being erased;
9. resident locally resolves/ignores/bounds the interruption;
10. resident returns to the previous matter or deliberately abandons it for a locally explainable reason;
11. resident eventually creates a factual World consequence;
12. later behavior reflects that changed fact;
13. resident may then become still or continue another locally grounded routine;
14. no provider cognition was needed anywhere in the sequence.

The system must also survive the negative case:
an irrelevant occurrence is perceived and **does not** hijack the resident.

---

## 7. Mandatory anti-cheat rules

R1 is **FAIL** if life is produced primarily by:

- random wandering;
- random destination selection presented as purpose;
- periodic chatter;
- periodic activity switching;
- a hidden scenario controller issuing resident commands;
- resident-ID-specific control logic;
- direct test mutation of resident private intent to force checkpoints;
- a timer whose only role is "do something new";
- debug/research code becoming runtime authority;
- a fake provider/stub selecting semantic plans;
- World mutations being counted as resident outcomes when the resident did not causally produce them.

Deterministic test perturbations may create external World facts.
They may not dictate the resident response.

---

## 8. Legitimate stillness

Stillness is a first-class state.

A resident standing still is not automatically dead.

R1 must distinguish:

### Quiet but alive
Examples:
- waiting for a known future condition;
- resting after a completed local matter;
- observing a relevant place;
- remaining at a chosen location because there is no unresolved local reason to move;
- maintaining a routine that requires no body movement.

The research lens can explain the reason from explicit state.

### Inert
Examples:
- no matter;
- no attention;
- no local evaluation;
- no ability to react to relevant change;
- no reason for stillness other than lack of code path.

A long deterministic quiet window should be included deliberately.

---

## 9. Interruption pressure

The interrupting occurrence must be selected so that two cases can be tested:

### Irrelevant / low relevance
Resident perceives it, but current life continues without semantic churn.

### Material local interruption
Resident visibly redirects enough to prove:
- attention can change;
- current execution can suspend or yield;
- continuing matter survives;
- local handling can terminate;
- prior matter can resume.

No LLM is available to tell the resident what the interruption "means".
R1 therefore pressures local situated judgement without pretending it is final semantic intelligence.

---

## 10. Material consequence pressure

R1 requires at least one resident-caused World state transition.

Preferred shape:
- simple;
- persistent;
- physically/world-authoritative;
- visible enough to inspect;
- relevant to the resident's current matter;
- able to influence later local behavior.

Examples are donors, not requirements:
- move/place an object;
- alter a small work state;
- open/close/change a local usable object;
- carry something from A to B;
- restore a local condition;
- discover checked absence and change the local plan.

Avoid building an economy or crafting system merely to satisfy R1.

---

## 11. Observation contract

R1 must be explainable from explicit causal state without hidden chain-of-thought.

Minimum research evidence:
- World tick/time;
- resident position/body state;
- current attention target/reason if any;
- current continuing matter(s);
- current execution and suspended execution if applicable;
- recent situated perceptions;
- local relevance classifications for materially tested events;
- factual World actions/outcomes;
- matter progression/terminalization reason;
- no provider request count other than zero;
- bounded lifecycle for observations/reasons used by the local mechanism.

World-only behavior should also be sufficiently legible that the debug panel is not the only place where life exists.

---

## 12. Determinism and replay

The initial R1 qualification should prefer deterministic conditions.

Required:
- fixed scenario seed/input where randomness exists;
- explicit World perturbation ticks;
- reproducible outcome order;
- no dependency on wall-clock provider latency;
- ability to rerun the exact experiment.

Determinism is an experimental instrument, not a requirement that future resident life be fully deterministic.

---

## 13. Long-window test

After the canonical arc passes, run a longer zero-provider window.

Purpose:
- expose accidental activity churn;
- expose event backlog growth;
- verify that quiet periods remain stable;
- verify that completed local events do not resurrect indefinitely;
- inspect whether matters naturally settle or continue;
- detect memory/evidence growth pathologies.

Do not add artificial stimuli merely to keep the trace visually busy.

---

## 14. R1 pass criteria

R1 earns **LOCAL-LIFE PASS** only if all are demonstrated:

1. provider request count is exactly zero;
2. resident has at least one continuing matter represented separately from body execution;
3. local execution progresses through actual World authority;
4. one irrelevant perceived event does not hijack life;
5. one material local interruption changes attention/execution without erasing identity/matter;
6. prior life resumes or locally terminates for an explicit reason;
7. resident causes at least one persistent factual World consequence;
8. later resident behavior reflects that consequence;
9. a quiet window is explainable as legitimate or exposed as inert;
10. the run does not rely on random wandering/chatter/periodic novelty;
11. no resident-ID-specific core path is required;
12. exact deterministic replay reproduces the relevant causal sequence;
13. a longer window does not accumulate unbounded unresolved local-event debt.

Passing this gate does **not** imply:
- personhood solved;
- semantic relevance solved;
- LLM integration ready;
- five-resident life solved;
- Owner living-world quality.

It proves only that there is finally a resident-local organism worth connecting to higher cognition.

---

## 15. Failure interpretation

Useful FAILs are expected.

Classify failures rather than hiding them:

- **LOCAL-BRAIN GAP** — resident lacks competence;
- **RELEVANCE GAP** — resident cannot prioritize local change;
- **MATTER GAP** — purpose/execution continuity is wrong;
- **WORLD-AFFORDANCE GAP** — environment provides insufficient grounded choices;
- **OBSERVABILITY GAP** — behavior exists but cannot be truthfully reconstructed/read;
- **AUTHORITY GAP** — resident/test/debug path mutates truth illegitimately;
- **HOMEOSTASIS GAP** — local events accumulate/retrigger instead of settling;
- **PERSONHOOD GAP** — behavior is technically valid but has no resident-specific reason.

Do not immediately fix a failure by adding an LLM call.

---

## 16. Implementation discipline

Before implementing:
1. inspect the current resident runtime, matter/run kernel, local execution seams and research scenario;
2. reuse proven causal primitives where appropriate;
3. do not wholesale port First Hearth;
4. recover donor behavior only where R1 needs it;
5. keep changes local and reversible;
6. write the first failing oracle before broad refactoring when practical;
7. avoid general frameworks until the specimen produces repeated pressure.

The first code change should make the R1 failure observable, not make a grand new architecture look complete.

---

## 17. Promotion after R1

**R1 passed on 2026-09-20.**

The shared local material and contact competences were reattacked through existing Janek deterministic and real-browser evidence during the R1 campaign and remained green.

Current promotion path:
- preserve R1 as the local-life baseline;
- build **R2 relevance / semantic metabolism** from the pressure failures R1 intentionally exposed;
- use Mira and Janek as complementary falsifiers;
- only then reintroduce real Luna for situations the local organism cannot honestly resolve.

If R1 fails:
- stay inside R1;
- repair the smallest causal weakness;
- rerun;
- do not escape into provider prompting or five-resident scale.

---

## Closing question

For every R1 change ask:

> **Did this make the resident better able to continue its own locally grounded life, or did it merely create more visible activity?**

Only the first counts.
