## 4. What R3 actually proved

### 4.1 Same evidence can acquire different resident-relative significance from private history

Executable authority:

`src/spc-next/r3-same-evidence-different-history.integration.test.ts`

Two otherwise equivalent resident specimens receive the same Janek sight-enter evidence.

At the R2 observation boundary:

- both observations are truthful;
- both remain observation-only;
- neither raw sight event automatically becomes semantic pressure.

Only the specimen with a relevant resident-owned open blocked actor matter receives matter-relative semantic significance.

The other specimen does not.

The differentiator is therefore resident history/state, not:

- resident name;
- random provider behavior;
- prompt wording;
- raw perception alone.

This satisfies the central R3 milestone.

### 4.2 Existing continuity state was sufficient for the first causal-personhood effect

R3 did **not** need a generic personality database or a needs/trait vector.

The first useful private self-state already existed in the continuity substrate:

- matter identity;
- origin evidence;
- semantic intent;
- current status;
- factual outcome history;
- interruption/suspension state.

`ResidentMatterRelevanceBridge` interprets that state narrowly and read-only.

Important correction:

The relevance effect is not intrinsically “promise-only”.

A resident-owned open blocked `communicate_actor` matter can make later contact with that actor relevant whether the matter began as:

- an accepted social responsibility; or
- another legitimate resident-owned causal matter.

This is desirable.

The causal fact is that **this resident has unfinished business involving this actor**.

`accepted_social_commitment` is one meaningful origin class, not a new universal personhood ontology.

### 4.3 A real social responsibility now has system-owned causal origin

Production materialization for grounded communicate commitments now records:

`accepted_social_commitment`

This evidence is not provider-declared flavor text.

It appears only after the existing causal chain has defended:

- exact private speech provenance;
- resident-specific perception;
- semantic admission;
- known target actor;
- grounded communicate intent;
- materialization into resident continuity.

Executable authority includes:

`src/spc-next/resident-causal-communicate-commitment.ts`

and the Ida causal-message vertical.

This closes the earlier gap where production communicate commitments were indistinguishable from generic cognition commitments.

### 4.4 Social responsibility has a real lifecycle rather than permanent moral weight

An active or suspended accepted social responsibility projects:

`open_social_responsibility`

into read-only choice support.

Suspension does **not** erase responsibility.

That is necessary for interruption continuity.

Once the matter becomes terminal, the open-responsibility relation disappears.

After factual fulfilment, the current choice substrate retains the factual outcome that is still relevant in bounded evidence, but does not keep a ghost “you still owe this” signal.

Historical autobiography about past promises remains a future memory/personhood question; it is deliberately not simulated by retaining active obligation semantics forever.

### 4.5 Competing-matter choice can no longer invent its causal rationale ex nihilo

Executable authority:

`src/spc-next/resident-life-choice-causal-support.ts`

`src/spc-next/resident-life-choice-owner.ts`

`worker/spc-next-life-choice.ts`

For `focus_matter`:

- the selected matter must be a real legal candidate;
- at least one support evidence id must be cited;
- every cited id must have existed before the decision;
- every cited id must belong to the exact selected matter's projected support;
- duplicate, invented and cross-matter support is rejected.

The Worker schema emits candidate-specific focus variants with candidate-specific allowed support ids.

A provider may still judge among genuinely supported competing matters.

The system does **not** hard-code:

> obligation always wins.

An ordinary matter can legally win if it cites its own real causal support.

Therefore R3 adds grounding without replacing semantic judgement with a designer priority table.

### 4.6 Real obligation-vs-ordinary ambiguity reaches the same choice boundary

The Ida causal-message integration now includes a real composition:

- B is a grounded accepted Ida→Janek communicate responsibility;

This proves a real **CHOICE EFFECT** without introducing a hard-coded winner.

### 4.7 Life choice now requires a real ambiguity reason

A higher-life choice can no longer piggyback on any arbitrary cognition batch.

`ResidentLifeChoiceOwner.prepare()` requires one exact `uncertainty` reason whose evidence set is the current deferred run set.

Therefore:

> “The provider happens to be thinking anyway, so let it rank the resident's other matters too”

is no longer legal.

This closes another route by which apparent personhood could have been manufactured opportunistically.

### 4.8 R2 per-reason lifecycle remains authoritative through R3 choice

A successful focus decision:

- settles the exact ambiguity reason;
- retains unrelated sibling pressure.

A rejected/stale/abandoned attempt requeues unresolved work.

A `defer_all` decision retains the ambiguity rather than consuming it.

This prevents semantic amnesia at the R2→R3 boundary.

### 4.9 Defer-all cannot recreate a cognition heartbeat

`ResidentLifeChoiceOwner` now receives an explicit authored `fixedDeltaSeconds`.

`reviewAfterSeconds` is converted into an exact `retainOriginUntilTick`.

The choice layer therefore does not assume 60 Hz and does not make a deferred ambiguity immediately eligible again.

Executable oracle proves:

- 3 seconds;
- fixed delta = 1 / 60;
- settlement tick = 32;
- next eligibility = tick 212;
- no batch at 211;
- ambiguity becomes eligible at 212.

This is directly relevant to the post-stress runaway failure.

### 4.10 Choice ambiguity now has coherent lifecycle identity

The old bridge encoded the candidate set into reason identity.

That allowed:

- B/C;
- then B/C/D

to become separate unresolved semantic events.

That is a direct event-necromancy risk.

R3 now uses one resident-scoped life-choice ambiguity identity.

Candidate runs are causal payload/evidence, not event identity.

The resulting lifecycle is:

- same candidate set -> deduplicated;
- changed unresolved set -> newer causal version, **superseded**;
- cleared ambiguity -> locally **settled / invalidated** with scheduler tombstone;
- later genuinely new ambiguity -> new **promoted** causal version.

A late old B/C batch cannot resurrect obsolete B/C after B/C/D became current.

This behavior is qualified both in focused lifecycle tests and in the real Mira multi-future B/C→B/C/D stale-provider vertical.

## 5. Important negative findings retained by R3

### 5.1 Generic matter origin is not enough to explain preference

Two legal matters with equally generic grounded origins can still be selected in opposite directions.

Both choices can be causally cited and legal.

Therefore causal support alone does not create broad personality.

This remains an explicit gap and protects the project from overclaiming.

### 5.2 Provider-authored concern prose is not trusted as personhood authority

A provider can create an obligation-like concern such as:

“I promised Janek…”

while citing evidence that contains only a neutral greeting.

The provenance pointer is real, but the semantic claim is fabricated.

Therefore generic provider-authored belief/concern prose is **not** accepted as causal proof that a promise, preference or relationship fact exists.

Future personhood dimensions need their own earned origins and lifecycle semantics.

### 5.3 Authored role/drives prose remains descriptive, not causal proof

The five-resident `role/drives` layer may remain useful context.

It is not evidence that the resident causally acquired:

- a preference;
- an aversion;
- an obligation;
- a relationship change;
- ownership;
- self-interest.

R3 passes without promoting role prose into authority.
