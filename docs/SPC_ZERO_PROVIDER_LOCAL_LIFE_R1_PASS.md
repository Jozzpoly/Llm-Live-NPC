## 4. Important semantic boundary preserved

R1 deliberately does **not** solve semantic-pressure settlement.

Most importantly:

> **local contact acknowledgement != semantic handling of speech content**

`Tak?` proves:
- the resident heard an addressed contact;
- local attention/body can react;
- bounded social micro-behavior can occur.

It does **not** prove:
- agreement;
- refusal;
- fulfilment;
- comprehension of the full semantic content;
- that higher cognition is no longer needed.

Accordingly, addressed `heard_speech` pressure remains unresolved in R1.

This is intentional.

R1 proves that an embodied resident can continue living while semantic pressure waits.
R2 must decide which pressure deserves escalation, settlement, supersession, expiry or continued retention.

## 5. Reusable local-brain substrate earned during R1

### `ResidentLocalMaterialDeliveryRoutine`

Shared by Mira and Janek.

Owns only procedural competence after a meaningful matter already exists:
- approach known object;
- pickup;
- preserve possession;
- move toward destination;
- place;
- reconcile factual outcome.

It does not decide why the resident should care.

### `ResidentLocalContactRoutine`

Shared by Mira and Janek.

Owns only bounded contact micro-behavior after contact has already been locally classified:
- suspend exact interrupted execution if present;
- stop;
- orient from private directional hearing evidence;
- acknowledge;
- hold briefly;
- terminate local contact;
- restore exact interrupted run if one existed.

It does not semantically answer the speech content.

Existing Janek browser interruption evidence re-passed after extraction, providing an independent resident falsifier for this shared competence.

## 6. Failures found during R1 that improved the architecture

R1 was not green by construction.

### Historical Janek boundary regression

Extracting shared material-delivery competence changed the externally observed pickup→delivery boundary of an already-qualified Janek donor.

Resolution:
- keep the shared routine;
- preserve the older donor's qualified public boundary in a thin compatibility wrapper;
- rerun old tests/browser evidence.

Result: PASS.

### Invalid late-contact oracle

The first quiet-wake test expected Mira to hear the player after she had moved roughly 595 units away while hearing radius was 420.

Resolution:
- do not teleport Mira;
- do not inject a percept;
- do not weaken hearing truth;
- place the participant physically inside the bounded workshop geometry from the beginning.

Result: real hearing causality PASS.

### Premature R1 semantic settlement

An early R1 implementation introduced a local scheduler-settlement seam.

Review found this crossed into R2 and risked recreating an old semantic bug:
local acknowledgement could accidentally be interpreted as handling the speech content.

Resolution:
- remove mutating R1 scheduler settlement;
- retain only read-only pending-pressure observation;
- allow unresolved semantic pressure to coexist with continued local life.

This correction materially strengthened the meaning of R1.
